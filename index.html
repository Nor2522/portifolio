About Nor

I'm a software developer and penetration tester who's spent the last several years working both sides of the fence: shipping production applications, and then trying to find every way to break into them.

That dual perspective is the core of how I work. As a developer, I write code that anticipates how it could be attacked. As a pentester, I think like an engineer who knows exactly where the corners were cut.

My work spans web application security, network penetration testing, secure API design, and red-team engagements — with a constant focus on turning findings into fixes, not just findings into reports.
