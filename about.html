About Nor

The short version: I build software, then I try to break it. The long version is below.

I'm a software developer and penetration tester who's spent the last several years working both sides of the fence: shipping production applications, and then trying to find every way to break into them.

That dual perspective is the core of how I work. As a developer, I write code that anticipates how it could be attacked — input validation, least-privilege access, sane session handling, none of it bolted on after the fact. As a pentester, I think like an engineer who knows exactly where the corners were cut under deadline pressure, because I've cut them myself.

My work spans web application security, network penetration testing, secure API design, and red-team engagements — with a constant focus on turning findings into fixes, not just findings into reports nobody reads.

Outside of client work, I spend time on CTFs, contributing to open-source security tooling, and building projects that solve real problems rather than padding a portfolio.
